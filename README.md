# Sciemo Customer Support Portfolio

Derick Gary’s customer success and technical support portfolio website.

## Open the website

[https://jermaine2322.github.io/Sciemo-customer-support/](https://jermaine2322.github.io/Sciemo-customer-support/)

The website includes an introductory homepage, nine linked article pages, a professional headshot, and downloadable resume and cover letter PDFs.

The support demonstrations use a fictional planning application. The professional case studies describe Derick’s actual experience.

## Hosting

Static HTML and CSS, hosted with GitHub Pages from the main branch and repository root. No installation or build step is required.
